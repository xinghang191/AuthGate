# Changelog

## 2.0.0

- Added per-character password masking that reveals only the character before the caret.
- Added an eye button to reveal or mask each password field independently.
- Password visibility resets when a field loses focus, the screen closes, or a form is submitted.
- Added localized visibility tooltips in Chinese and English.

## 1.0.0

- Initial release with GUI registration, login, password changes, account lockout, and administrator commands.
